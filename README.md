# Botbusters 13531 · Guía de programación FTC

Guía en español para los alumnos del equipo: instalación, setup, conexión al Control Hub, estructura del código, chasis, intake e indexer.

**Abrir la guía:** https://ddiegovilla.github.io/botbusters-ftc-docs/

## Publicación

GitHub Pages publica la raíz de la rama `main`. El archivo `.nojekyll` permite servir directamente el HTML, CSS, JavaScript y las imágenes.

Cada cambio que se sube a `main` actualiza la página automáticamente.

## Editar la guía

- `index.html`: contenido y ejemplos de código.
- `styles.css`: diseño adaptable y temas claro/oscuro.
- `app.js`: navegación, búsqueda, copia y visor de imágenes.
- `lesson-code.js`: presentación del código.
- `assets/`: logos, fotos y capturas.

Para revisar una edición localmente:

```sh
python3 -m http.server 4173
```

Abre http://localhost:4173 en el navegador.
